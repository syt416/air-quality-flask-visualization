全国城市空气质量数据可视化大屏

项目简介 
本项目基于 Python Flask + Pandas + ECharts 开发，是一套轻量级空气质量数据分析可视化系统。 项目采用公开 CSV 数据集，无需依赖 MySQL 数据库，通过 Pandas 完成数据读取、清洗、分组统计， 后端编写接口向前端提供结构化数据，前端使用 ECharts 实现地图、趋势图、柱状图、饼图多维度可视化展示。 

技术栈 
后端 
Python Flask：搭建 Web 服务与接口开发
Pandas：数据读取、清洗、聚合统计  

前端 
ECharts：实现地图、折线图、柱状图、饼图可视化 
HTML / 原生 JavaScript：页面结构与数据交互 
数据 - 公开空气质量 CSV 数据集 - 轻量化文件存储，无需数据库部署 

项目功能亮点 
1. 全国城市 AQI 空气质量地理分布地图展示 
2. 重点城市空气质量时间趋势变化分析 
3. 全国污染程度 Top10 城市排行可视化 
4. 多类污染物平均占比结构分析 
5. 整体数据总量统计展示 
6. 前后端分离架构，接口与视图解耦 

项目优势 
采用 CSV + Pandas 轻量化方案，无需安装 MySQL，部署简单、开箱即用 ,数据经过分组、求平均、过滤匹配，具备完整数据分析流程;代码结构清晰，接口设计规范，适合课程设计、毕设与个人作品集 

本地运行步骤 
1.安装依赖 ```bash pip install flask pandas ``` 
2.启动后端服务 ```bash python app.py ```
3.浏览器访问 ``` http://127.0.0.1:5000 ``` 
 
补充说明 - 数据源为网络公开空气质量数据集，仅用于学习与课程设计 - 项目未使用数据库，采用文件读取方式，降低环境依赖，方便演示与部署
